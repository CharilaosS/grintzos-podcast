# π. Ἰωάννης Γρίντζος — Ὁμιλίες (podcast feed)

Ἀνεπίσημο podcast RSS μὲ τὶς ὁμιλίες τοῦ π. Ἰωάννου Γρίντζου ἀπὸ τὴν ἱστοσελίδα
τοῦ Ἱεροῦ Ἡσυχαστηρίου Ἁγίας Τριάδος Πανοράματος (agia-triada-panorama.gr).

Τὰ ἠχητικὰ **δὲν** ἀντιγράφονται· κάθε ἐπεισόδιο δείχνει ἀπευθείας στὸ mp3 τῆς ἱστοσελίδας.

**Feed URL:** https://charilaoss.github.io/grintzos-podcast/feed.xml

## Πῶς δουλεύει

- `build_feed.py` διαβάζει τὴ λίστα `/audio/` (ὅλες οἱ σελίδες), κρατᾶ ὅσες ὁμιλίες ἀναφέρουν τὸν π. Ἰωάννη στὸν τίτλο, καὶ γράφει `docs/feed.xml`.
- `sizes.json` κρατᾶ τὰ μεγέθη τῶν mp3 ὥστε νὰ γίνεται HEAD μόνο γιὰ νέα ἀρχεῖα.
- GitHub Actions τρέχει κάθε μέρα καὶ κάνει commit τὸ νέο feed· τὸ GitHub Pages σερβίρει τὸν φάκελο `docs/`.

## Τοπικὰ

```bash
python3 build_feed.py
```
